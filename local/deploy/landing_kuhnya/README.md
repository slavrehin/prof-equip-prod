# Лендинг «Кухня» (/kuhnya/) — стартовое содержимое

Собран по брифу `брифы направления/бриф Кухня.docx` (ноябрь 2026) на компоненте `custom:direction.landing`.

- `data.json` — блоки, слайды, преимущества, форматы, галерея, FAQ, привязки (проекты, бренды, статьи, новость) и SEO.
  Связи ищутся по символьным кодам. Картинки — свои JPEG-копии фото из галерей проектов в `files/landing/kuh/`
  (не общие с галереями файлы: замена картинки в админке лендинга не удалит фото проекта).
- `brief/image1.png` — референс из брифа (блок «Решения» прачечной).
- `import.php` — копия `landing_tekstil/import.php`.

## Порядок выкладки

1. Файлы (деплой) и миграция `2026-11-25-landing-kuhnya-structure.php` (свойства LAND_* у инфоблока `kuhnya`).
2. Снимок свойств элемента направления, затем импорт:

```bash
mysqldump … --where="IBLOCK_ELEMENT_ID=<ID элемента kuhnya>" <db> b_iblock_element_property > before.sql
php local/deploy/landing_kuhnya/import.php --dry
php local/deploy/landing_kuhnya/import.php
```

Повторный запуск безопасен: файлы и строки `b_file` переиспользуются (EXTERNAL_ID `landing-sync-<md5 пути>`),
JSON-свойства, привязки и SEO перезаписываются целиком — правки, сделанные в админке после импорта, затрёт.

3. Проверка: `/kuhnya/` отдаёт 200, H1 «Оснащение профессиональных кухонь под ключ», 8 карточек RATIONAL с ценами, 7 проектов.
