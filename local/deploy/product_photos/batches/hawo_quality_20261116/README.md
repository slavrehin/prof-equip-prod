# Hawo: улучшенные фото на белом фоне

Пять фотографий для трех карточек. Обработаны встроенным image_gen на основе реальных фото: белый фон, очистка изображения. Это обработанные изображения, не неизмененные оригиналы. Общие виды 636 и 637 взяты из отдельных изображений каталога Wavepoint; для 638 найдены оригиналы 2832×4248 и 1881×2821 вместо 233×350. Новые ракурсы не генерировались. Промпты в prompts.json, источники и SHA-256 в map.json.

Замена существующих фото: `php local/deploy/product_photos/import.php hawo_quality_20261116 --force --log=/path/rollback.json`. Перед применением — резервная копия БД и пробный запуск `--force --dry`. Только локально и dev.prof-equip.ru.
