# Битрикс24 #8627 — новый формат проектов

34 проекта из четырёх чек-листов; тексты DOCX и изображения из приложений задачи.
Идентификаторы вложений актуального чек-листа сверены с выгрузкой от 7 ноября 2026.
`projects.json` содержит источники и SHA-256 DOCX; изображения — JPEG до 1920 px,
полученные из приложений, без изменения содержания. Для изображений записаны SHA-256.

Импорт разрешает ссылки по CODE в текущем окружении, без переноса числовых ID.
Пишет LIST, INFO_TITLE, BLOCKS, BRANDS, подборку CATALOG_PRODUCT_1 и SORT.
Существующие галереи и обложки сохраняет, пустые заполняет из приложений.
DETAIL_TEXT и даты реализации остаются историческими; отображаются новые BLOCKS.
Первые четыре проекта: MANTERA (прачечная), RUMA, Riviera, ENZO; остальные обновлённые
проекты идут перед прежними. Первая страница и AJAX используют одинаковую сортировку.

Перед запуском — резервная копия базы. Снимки изменяемых элементов сохраняются
в отдельный закрытый каталог вне document root. Без `--apply` записи нет.
Выполнять из корня сайта:

```sh
php local/deploy/projects_b24_8627_20261116/import.php
php local/deploy/projects_b24_8627_20261116/import.php --apply --backup-dir=/root/backups/task_8627_dev_20261116
```

На прод переносить только после согласования результата на dev, с отдельной резервной
копией и явным `--allow-production`. База dev на прод не переносится.
Повторный запуск не должен создавать изменений или дубликатов файлов.
Импорт применён на local и dev; повторный dry-run в обоих окружениях даёт `changed: 0`.
Перед `deploy_dev.sh` проверять локальный dry-run: он полностью заменяет базу dev локальной.

## Недостаток исходных данных

- «Стандарт чистоты», DoubleTree Новосибирск, «Кремлёвский»: DOCX в приложениях нет;
  записи не создаются и тексты не придумываются. Проверка текущих баз dev/prod не нашла
  элементов «Стандарт чистоты» и DoubleTree Новосибирск по этим названиям. Существующий
  «Кремлёвский» активен и доступен на проде, но в этот импорт не входит.
- В двух проектах сохранены десять уникальных отсутствующих брендов с учётом регистра названий.
  StandArt: HiCold, Polair, Abat, Forcar, Vidotto, Kemplex, Wega, Carpigiani, EQTA.
  «Сыры Кубани»: Polair, Frostor, HiCold, Abat. Названия сохранены в блоке «Другие бренды
  проекта». Для остальных работают привязки BRANDS. Создание новых страниц и логотипов
  для отсутствующих брендов в этот импорт не входит.
- Ibis: в DOCX бренд не указан; существующая привязка не меняется.
- Silko из DOCX соответствует существующему Silco (`silco`), ALPHA by JENSEN —
  существующему JENSEN. Повторяющиеся ссылки на товары и параметр ysclid удалены.

## Проверка

Проверять фактические свойства после записи, HTTP страниц, галереи и изображения,
ссылки на 28 карточек товаров (в восьми проектах), первые четыре карточки списка,
совпадение порядка первой порции и AJAX. Повторить dry-run: `changed` должен быть 0.
Существующие страницы «Кремлёвский», StandArt и «Сыры Кубани» на проде возвращают HTTP 200.
