# custom:direction.landing — лендинг направления

Страница `/prachechnaya/` (и следующие направления) собирается из админки, в коде текстов нет.

## Где что редактируется

**Весь контент лендинга направления правится в одном месте — в карточке элемента направления**
(Контент → Направления → «Прачечная (направление)» → элемент → вкладка **«Лендинг»**). Отдельных инфоблоков
под лендинг нет. Новые лендинги делать так же.

Вкладка «Лендинг» — свойства элемента направления. Их рисует собственный тип свойства
«Лендинг: список карточек» (`local/php_interface/include/landing_editor.php`): строки с полями, кнопки
«добавить / удалить / выше / ниже», загрузка картинок. В базе — JSON.

| Что на странице | Свойство элемента направления |
|---|---|
| Заголовок, вступление, кнопки, формы, пункт якорного меню каждого блока; тезисы «Запчастей», факты «ТЗ», темы финальной формы | **Заголовки и тексты блоков** (`LAND_BLOCKS`). «Показывать» снято — блок исчезает со страницы. Порядок пунктов меню = порядок блоков страницы |
| Слайды первого экрана (фон — картинки слайда; H1 = заголовок первого слайда, только если пусто поле SEO «Заголовок элемента») | **Слайды первого экрана** (`LAND_SLIDES`) |
| H1 страницы (визуально скрыт, отдельно от баннеров) | вкладка **SEO** → «Заголовок элемента» (`ELEMENT_PAGE_TITLE`) |
| 4 преимущества под слайдером | **Преимущества под слайдером** (`LAND_ADVANTAGES`) |
| Вкладки «Решения» | **Решения (вкладки)** (`LAND_SOLUTIONS`) |
| Шаги «Проектирование» | **Этапы проектирования** (`LAND_STEPS`; у каждого этапа можно добавить фото справа от текста) |
| Кольцо «Круговая гарантия» (ровно 4 элемента) | **Круговая гарантия** (`LAND_GUARANTEE`) |
| Статьи и новости «Экспертного центра» | **Статьи блога / Новости** (`LAND_MAT_BLOG`, `LAND_MAT_NEWS`, обычные привязки). Крупная карточка — самая свежая статья |
| Проекты, бренды | Свойства «Портфолио» и «Производители» того же элемента. Текст/цифры/теги карточки проекта — свойства проекта «Карточка на лендинге: …» |
| Оборудование в наличии | Флажок «В наличии» у товара (`STOCK_BADGE`); раздел каталога, лимит и подпись цены — в блоке «В наличии» |
| Телефон/e-mail/адрес | Инфоблок «Контакты», элемент с отметкой MAIN |
| title / description | Вкладка «SEO» того же элемента |
| Заявки | «Сервисы → Веб-формы → Лендинг направления» (`SIMPLE_FORM_4`), поле «Источник лида» |

Какие поля есть у каждого свойства — `profequip_LandingSchema()` в `landing_editor.php`; добавить поле = добавить
строку в схему (и прочитать его в `component.php`).

## Новое направление

1. Создать/открыть инфоблок направления и его элемент (символьный код элемента = код направления).
2. Создать свойства лендинга и вкладку «Лендинг»: `profequip_LandingEnsureDirectionProps($iblockId)` (в миграции).
3. Заполнить вкладку «Лендинг» в админке (образец — «Прачечная»; стартовое содержимое —
   `local/migrations/2026-09-18-landing-prachechnaya-seed.php`).
4. На странице: `IncludeComponent('custom:direction.landing', '', ['DIRECTION_CODE' => 'kuhnya', 'DIRECTION_IBLOCK_CODE' => 'kuhnya'])`.

## Формы

Все формы — одна веб-форма `SIMPLE_FORM_4`, класс `fb-form` подхватывает общий `js/dev.js` (капча SmartCaptcha, fetch на
`/local/ajax/form/?template_form=landing`, ответ JSON из шаблона `form.result.new/landing`). Валидация, маска телефона,
вложения (до 3 файлов) и источник лида — `assets/js/direction-landing.js`. Лид в Битрикс24 — `profequip_SendLandingLeadToBitrix24`
(`php_interface/include/landing.php`); на test3 лиды не уходят.

## Кэш

Данные блоков кэшируются на час с тегами инфоблоков — правка элемента направления в админке видна сразу. Товары «В наличии» и цены — без кэша.
