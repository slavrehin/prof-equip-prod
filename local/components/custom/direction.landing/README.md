# custom:direction.landing — лендинг направления

Страница `/prachechnaya/` (и следующие направления) собирается из админки, в коде текстов нет.

## Где что редактируется

**Весь контент лендинга направления правится в одном месте — в карточке элемента направления**
(Контент → Направления → «Прачечная (направление)» → элемент → вкладка **«Лендинг»**). Отдельных инфоблоков
под лендинг нет. Новые лендинги делать так же.

Вкладка «Лендинг» — свойства элемента направления. Их рисует собственный тип свойства
«Лендинг: список карточек» (`local/php_interface/include/landing_editor.php`): строки с полями, кнопки
«добавить / удалить / выше / ниже», загрузка картинок. В базе — JSON.

| Что на странице | Свойство элемента направления |
|---|---|
| Заголовок, вступление, кнопки, формы, пункт якорного меню каждого блока; тезисы «Запчастей», факты «ТЗ», темы финальной формы | **Заголовки и тексты блоков** (`LAND_BLOCKS`). «Показывать» снято — блок исчезает со страницы. Порядок пунктов меню = порядок блоков страницы |
| Якорное меню: подписи, порядок, свои пункты | **Заголовки и тексты блоков** → «Якорное меню» → «Пункты меню» (подпись + `#блок` или адрес). Заполнено — меню строится только по этому списку (так у «Прачечной»); пусто — из поля «Пункт якорного меню» каждого блока (Кухня, Текстиль). Пункт на скрытый блок не выводится |
| Слайды первого экрана (фон — картинки слайда; H1 = заголовок первого слайда, только если пусто поле SEO «Заголовок элемента») | **Слайды первого экрана** (`LAND_SLIDES`) |
| H1 страницы (визуально скрыт, отдельно от баннеров) | вкладка **SEO** → «Заголовок элемента» (`ELEMENT_PAGE_TITLE`) |
| 4 преимущества под слайдером | **Преимущества под слайдером** (`LAND_ADVANTAGES`) |
| Вкладки «Решения» | **Решения (вкладки)** (`LAND_SOLUTIONS`) |
| Шаги «Проектирование» | **Этапы проектирования** (`LAND_STEPS`; у каждого этапа можно добавить фото справа от текста) |
| Кольцо «Круговая гарантия» (ровно 4 элемента) | **Круговая гарантия** (`LAND_GUARANTEE`) |
| Статьи и новости «Экспертного центра» | **Статьи блога / Новости** (`LAND_MAT_BLOG`, `LAND_MAT_NEWS`, обычные привязки). Крупная карточка — самая свежая статья |
| Проекты, бренды | Свойства «Портфолио» и «Производители» того же элемента. Текст и цифры карточки проекта — свойства проекта «Карточка на лендинге: …». Теги под описанием — первые 4 бренда из свойства проекта «Бренды» (`BRANDS`); если брендов нет — «Карточка на лендинге: теги» (`CARD_SCOPE`), тоже не больше 4 |
| Категории каталога (после формы под проектами, «Прачечная») | Свойство «Категории каталога» (`LAND_CATS`): символьный код раздела — название, ссылка и картинка берутся из раздела; своя «Картинка» карточки важнее. Заголовок над карточками — «Заголовки и тексты блоков» → «Категории каталога» (пусто — без заголовка) |
| Оборудование в наличии | Флажок «В наличии» у товара (`STOCK_BADGE`); раздел каталога, лимит и подпись цены — в блоке «В наличии» |
| Телефон/e-mail/адрес | Инфоблок «Контакты», элемент с отметкой MAIN |
| title / description | Вкладка «SEO» того же элемента |
| Заявки | «Сервисы → Веб-формы → Лендинг направления» (`SIMPLE_FORM_4`), поле «Источник лида» |

Какие поля есть у каждого свойства — `profequip_LandingSchema()` в `landing_editor.php`; добавить поле = добавить
строку в схему (и прочитать его в `component.php`).

## Новое направление

1. Создать/открыть инфоблок направления и его элемент (символьный код элемента = код направления).
2. Создать свойства лендинга и вкладку «Лендинг»: `profequip_LandingEnsureDirectionProps($iblockId)` (в миграции).
3. Заполнить вкладку «Лендинг» в админке (образец — «Прачечная»; стартовое содержимое —
   `local/migrations/2026-09-18-landing-prachechnaya-seed.php`).
4. На странице: `IncludeComponent('custom:direction.landing', '', ['DIRECTION_CODE' => 'kuhnya', 'DIRECTION_IBLOCK_CODE' => 'kuhnya'])`.

## Формы

Все формы — одна веб-форма `SIMPLE_FORM_4`, класс `fb-form` подхватывает общий `js/dev.js` (капча SmartCaptcha, fetch на
`/local/ajax/form/?template_form=landing`, ответ JSON из шаблона `form.result.new/landing`). Валидация, маска телефона,
вложения (до 3 файлов) и источник лида — `assets/js/direction-landing.js`. Лид в Битрикс24 — `profequip_SendLandingLeadToBitrix24`
(`php_interface/include/landing.php`); на test3 лиды не уходят.

## Кэш

Данные блоков кэшируются на час с тегами инфоблоков — правка элемента направления в админке видна сразу. Товары «В наличии» и цены — без кэша.

## Кухня (/kuhnya/)

Элемент: Контент → «Направления: Кухня» → «Оборудование профессиональной кухни» (инфоблок `kuhnya`), вкладка «Лендинг».
Бриф — `брифы направления/бриф Кухня.docx` (ноябрь 2026); стартовое содержимое — `local/deploy/landing_kuhnya/` (data.json + import.php).
Порядок секций задан картой `$sectionOrderMaps['kuhnya']` в `template.php` (CSS `order`), не порядком в админке:
слайдер и пиктограммы · проекты + форма «Подберём решение» · RATIONAL с ценами · галерея кухонь · бренды ·
форма «Есть планировка или ТЗ?» · форматы заведений · сервис и запчасти · партнёрам · отзывы · экспертный центр · FAQ · финальная форма.

| Что на странице | Где править |
|---|---|
| Карточки RATIONAL с ценами | «Заголовки и тексты блоков» → «Оборудование в наличии» → «Товары списком (символьные коды)» — по коду в строке, порядок как в списке. Флажок «В наличии» у товара не нужен; плашка «В наличии» — только у реально складских позиций (флажок или «Наличие» = СКЛАД МОСКВА). Пусто — товары с флажком «В наличии» |
| Галерея кухонь (1 крупное + 4 фото) | Свойство «Библиотека: фото»: фото, подпись, ссылка на проект |
| Форма «Есть планировка или ТЗ?» | Блок «Форма «Уже есть план или ТЗ?»» (секция `#design`; этапы проектирования у Кухни не заполнены) |
| Форматы заведений (Ресторан, частный дом, отель, столовая, кофейня) | Свойство «Решения (вкладки)» |
| Сервис и запчасти | Блок «Запчасти» (форма подбора, фото справа) |
| Партнёрам | Блок «Партнёрам» (тёмная секция). «Главная кнопка: адрес» — прямая ссылка на файл, когда появятся документы для партнёров: кнопка будет скачивать и слать цель `kuhnya_partner_dl` |
| Отзывы | Свойство «Отзывы» + флажок «Показывать» у блока «Отзывы» (сейчас выключен — ждём отзывы) |

Остальные блоки из прежнего брифа (развилка, полоса доверия, чек-лист, сертификаты, сравнение, поставка, сервис,
кольцо гарантии, мобильная панель) по-прежнему доступны во вкладке «Лендинг» и включаются флажком «Показывать».
Чипы фильтра проектов — свойство проекта «Тип объекта» (`OBJ_TYPE`) и поле блока «Проекты» «Фильтр по типу объекта»
(сейчас пусто — фильтра нет).

Цели Метрики (только Кухня, префикс из `$directionCfg` в `template.php`): `kuhnya_hero_cta`, `kuhnya_fork_select` {scenario},
`kuhnya_checklist`, `kuhnya_lead` {topic}, `kuhnya_lead_file` {topic}, `kuhnya_catalog`, `kuhnya_partner_dl`, `kuhnya_partner_request`,
`kuhnya_tel`, `kuhnya_scroll_50`, `kuhnya_scroll_75` — их нужно завести в счётчике как JS-события. Общие `send_form` и цель = источник лида
по-прежнему отправляются.
